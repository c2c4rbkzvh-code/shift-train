# SHIFT / TRAIN 2.1 – korrigering

Rättar JavaScript-felet `olym is not defined` som gjorde att dagens träningsprogram inte visades i version 2.0. Dagens styrka och WOD, manuellt passval, tidsval och loggning har testats i Chromium.

## Uppdatera GitHub Pages

Ersätt endast `index.html` i repositoryts huvudmapp på `main` med filen från detta paket. Övriga filer kan vara kvar. Vänta på grön bock under Deployments och ladda om sidan i Safari.

Befintliga träningsdata ligger kvar i webbläsarens lokala lagring under samma nyckel som v2.0.

Obs: skiftrotationen är fortfarande preliminär och WOD-skalning behöver vidareutvecklas.
